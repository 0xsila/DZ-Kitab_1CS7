# DZ-Kitab

![CI/CD](https://github.com/BillalBRAHAMI/DZ-Kitab_1CS7/actions/workflows/ci.yml/badge.svg?branch=Billal)

Plateforme collaborative de gestion et d’échange de livres, développée par une équipe d’étudiants.

## Dépôt
- **GitHub** : https://github.com/BillalBRAHAMI/DZ-Kitab_1CS7 (branche Billal)

## Structure du projet
- `backend/` : API Express.js, MySQL, gestion des utilisateurs, annonces, etc.
- `frontend/` : Application React (Vite)
- `docker-compose.yml` : Lancement local de l’ensemble (backend, frontend, base de données)

## CI/CD
- Pipeline GitHub Actions : build, tests, build Docker, déploiement (voir badge ci-dessus)

## Déploiement en ligne
- **Frontend** : https://frontend-x7sg.onrender.com
- **Backend** : https://backend-b1zf.onrender.com

## Bonnes pratiques
- Fichiers sensibles ignorés via `.gitignore`
- Documentation présente dans chaque dossier
- Historique de commits propre et lisible
- (À améliorer) Utilisation de Pull Requests pour les fonctionnalités majeures
